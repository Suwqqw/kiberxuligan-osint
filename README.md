# KIberXuligan OSINT Workstation

Локальная веб-панель для сбора и визуализации информации из открытых источников (OSINT). Объединяет несколько поисковых движков, модуль анализа изображений и валидацию телефонных номеров в едином интерфейсе на базе FastAPI.

Работает полностью на localhost без передачи телеметрии или запросов на сторонние серверы аналитики.

---

## Основные возможности

- **Агрегация поиска по никнеймам**: одновременный опрос открытых профилей через подключенные CLI-модули.
- **Интерактивный граф (Vis.js)**: построение карты связей между найденными учетными записями и источниками.
- **Анализ фото и метаданных**:
  - Детекция лиц и расчет биометрического кропа (OpenCV).
  - Оценка резкости снимка по дисперсии Лапласиана.
  - Перцептивное хэширование (dHash) и вычисление цифрового отпечатка SHA-256.
  - Извлечение EXIF-тегов и GPS-координат.
- **Телефонный справочник**: проверка формата, определение региона и оператора связи.

- **Фронтенд**: Vanilla JS, HTML5, CSS3, Vis.js

## Быстрый старт

### Требования
- Python версии 3.10 или выше
- Windows 10/11 или Linux

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ВАШ_АККАУНТ/kiberxuligan-osint.git
cd kiberxuligan-osint
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите сервер:
```bash
python osint_hub/server.py
```
Панель откроется по адресу `http://127.0.0.1:8888`.

*(На Windows для запуска в один клик достаточно запустить `START.bat`, который сам проверит зависимости.)*
